# site/ — сайт проекта для РНПК

Статический HTML + CSS. Никакой сборки: `index.html` открывается двойным
кликом с диска и работает так же, как на сервере — JavaScript на странице нет
вообще.

```
site/
  index.html   вся страница
  style.css    оформление
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**,
ветка `main` (или текущая), папка **`/site`**. Через минуту страница будет по
адресу `https://<пользователь>.github.io/<репозиторий>/`.

## Правило для чисел

Каждое число на странице либо измерено нами — тогда под ним указан файл в
`reports/`, откуда оно взято, — либо взято из статьи, тогда рядом стоит ссылка
на источник. Третьего варианта нет.

Числа проверены перед вёрсткой; расхождения с первоначальными формулировками
исправлены в пользу того, что реально написано в источнике:

| на странице | как проверено |
|---|---|
| 3,3–23,1 % | собственный результат обзора Age and Ageing afaf231, а не фраза «до 30 %» из его введения |
| 6 → 50 → 100 % | оценка из более ранней литературы, которую цитирует PMC4234513; подписано именно так |
| 2,66× | подтверждено; доверительный интервал не подтверждён и поэтому не приводится |
| 112 000 / 89 235 / 443 497 | подтверждено дословно |
| 69 % (IQR 19–84) | El Morabet et al. 2018; «две трети» заменено точным значением с размахом |
| 99,98 % | `reports/split_comparison.csv`, сид 0; по трём сидам 99,94–99,98 % |
| 0,868 / 0,915 | `reports/phase_a_results.csv`, `reports/phase_a_full_rf.csv`, среднее по 5 сидам |
| 0,885–0,954 | `reports/degree_shortcut_probe.csv`; приведён диапазон, а не верхнее значение |
| 0,048 / 0,500 | `reports/calibration.md` |

Ширины столбцов на графике вычислены из самих значений по шкале 0,5–0,95 и
сверены программно.

## Чего на странице нет

Экран «что обещает область» написан как наш собственный структурный аргумент,
без ссылок на конкретные работы: до полных текстов GNN-DDI, MIRACLE и SSI-DDI
доступа не было, а приписывать авторам формулировки из их разделов ограничений,
не прочитав эти разделы, нельзя. Появятся тексты — добавим цитаты.
