## 8. Что может обесценить работу

* **Разметка механизмов из текстовых описаний.** 86 типов TDC — это текст, а не
  PK/PD-онтология. Маппинг вводит субъективность; без явной mapping confidence и
  категории AMBIGUOUS он превратится в выдуманные факты.
* **Мощность эксперимента.** Измеренный межпрогонный σ = 0.036 при пяти сидах.
  Эффекты меньше ~0.04 неразличимы. Если mechanism-awareness даст +0.02,
  корректный вывод — «не обнаружено», а не «не работает».
* **Circularity биологических рёбер.** Если pathway-рёбра выводятся из тех же
  аннотаций, из которых получены метки, задача становится circular.
  `leakage_audit` существует ровно для этой проверки и должен запускаться до
  любых выводов.
* **Near-duplicate структуры.** Novel×novel теряет смысл, если в обучении есть
  почти идентичная молекула. Нужен порог по сходству, а не только по идентификатору.
