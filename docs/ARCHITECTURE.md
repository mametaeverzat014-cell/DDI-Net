# ARCHITECTURE.md

Система строится **вокруг двух научных слоёв**, а не вокруг одной модели. Это
различие должно проходить через всю документацию и все отчёты.

---

## Слой 1 — честная оценка предсказания взаимодействий

**Вопрос:** насколько падает качество, когда контролируются утечка при
разбиении и обучение на коротких путях (shortcut learning)?

**Статус:** реализован, эксперимент идёт.

**Что уже измерено** (Фаза A, классические модели):

| Модель | Published-протокол | Честный протокол |
|---|---|---|
| Полный Random Forest | 0.915 | 0.763 |
| Degree-only (два числа) | 0.868 | 0.549 |

**Что измеряется сейчас** (Фаза A-2, графовые сети, 70 прогонов): те же
величины для GINE и двухуровневой архитектуры, плюс контроль `gine_degree`.

Этот слой **самодостаточен**: он даёт результат независимо от того, будет ли
построен слой 2.

---

## Слой 2 — механистическое обобщение

**Вопрос:** улучшают ли молекулярные и биологические представления обобщение на
структурно новые соединения?

**Статус:** заблокирован отсутствием биологических данных
(см. `DATA_REQUIREMENTS.md`).

**Почему это не тот же вопрос.** Слой 1 спрашивает «сколько из заявленного
качества настоящее». Слой 2 спрашивает «можно ли перенести выученный механизм
на молекулу, которой не было в обучении». Первый вопрос про методику оценки,
второй — про способность модели.

```
   Молекула A                              Молекула B
       |                                       |
  [2D GINE]  [3D энкодер, опционально]    [2D GINE]  [3D, опц.]
       |            |                          |          |
       +-----+------+                          +-----+----+
             |                                       |
    представления подструктур              представления подструктур
             |                                       |
             +--------------+     +------------------+
                            |     |
                   CROSS-MOLECULAR МОДУЛЬ
                            |
                 представление взаимодействия
                            |
              ГЕТЕРОГЕННЫЙ БИОМЕДИЦИНСКИЙ ГРАФ
              (белки, ферменты, транспортёры, пути)
                            |
                    ВЫВОД МЕХАНИЗМА
                        /       \
                    PK-голова  PD-голова
                        \       /
                            |
                   предсказание DDI
                            |
        +---------+---------+---------+----------+
        |         |         |         |          |
  неопределён- OOD-балл  уровень  молекулярное  counterfactual
     ность              evidence  объяснение
```

### Режимы для ablation

Архитектура обязана запускаться в пяти режимах — иначе вклад каждого уровня
неизмерим:

| Режим | Состав | Реализован |
|---|---|---|
| A | только молекулярный | **да** (`gine`) |
| B | молекулярный + 3D | нет |
| C | молекулярный + граф | **да** (`dual`) |
| D | молекулярный + механизм | нет (нет данных) |
| E | полная модель | нет (нет данных) |
| — | контроль: молекулярный + степень | **да** (`gine_degree`) |

Режим-контроль добавлен не спецификацией, а измерением: эмбеддинг сетевой ветки
восстанавливает степень узла с R² = 0.885–0.954, поэтому нужно проверить,
воспроизводится ли весь её вклад двумя скалярами.

## Принципы, которым архитектура подчинена

**Модульность ради ablation, а не ради красоты.** Каждый уровень включается
флагом конфигурации, и ширина слоя слияния следует за флагами — отключённая
ветка не оставляет мёртвых параметров, которые кормятся нулями. Иначе сравнение
режимов нечестно.

**Коммутативность обязательна.** Взаимодействие симметрично: f(A,B) = f(B,A).
Все члены слияния используют `*` и `|·|`, поэтому симметрия точная, а не
приближённая. Это отступление от конкатенации, принятой в большинстве
публикаций, и сам разрыв между двумя кодировками — измеряемая величина.

**Граф сообщений строится только из обучающих рёбер.** Проверяется
`assert_no_evaluation_edges` по каждому не-обучающему бакету, по префиксу имени,
а не по списку — схемы называют бакеты по-разному.

**Никаких изобретённых компонентов внутри сравнения.** Модели слоя 1 намеренно
стандартны: если бы архитектура была своей, падение метрик при честном сплите
можно было бы объяснить и сплитом, и архитектурой. Собственная архитектура —
отдельный блок **после** слоя 1.

## Что может обесценить архитектуру

* **Циркулярность.** Если рёбра биологического графа выводятся из тех же
  аннотаций, из которых получены метки, задача становится замкнутой.
  `features/ddi_graph.py::leakage_audit` существует ровно для этой проверки и
  должен запускаться до любых выводов о вкладе биологии.
* **Мощность.** Измеренный межпрогонный σ = 0.036 при пяти сидах. Эффекты
  меньше ~0.04 неразличимы. Архитектурное улучшение на +0.02 даст вывод «не
  обнаружено», а не «работает».
* **Степень как короткий путь.** Уже измерено, что сетевой уровень кодирует
  степень почти полностью. Любое утверждение о «интеграции топологии» обязано
  быть проверено против контроля `gine_degree`, иначе оно необоснованно.
