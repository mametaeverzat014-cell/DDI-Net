## 4. Adversarial cases

| Case | Pass | Detail |
|---|---|---|
| unrelated adverse effect in the same label | yes | hepatotoxicity sentence without the partner is not assigned to the pair |
| outcome and partner in separate sections | yes | bleeding (Warnings) + warfarin (Drug Interactions) give no bleeding outcome |
| plausible but undocumented mechanism | yes | DB01394+DB01071: 1 hypothesis(es), all research-only; status research_prediction_only |
| outdated label next to a current one | yes | only the most recent label is read (documents: ['00000000-0000-0000-0000-00000000ad04']) |
| several excerpts from one document | yes | two sentences of one label: two excerpts, one source document |
| contradictory sources | yes | DrugBank exposure increase kept; label no-effect sentence shown as disagreement, neither wins |
| ambiguous DrugBank drug order | yes | both drugs inhibitor and substrate: no affected drug named |
| label names both drugs without asserting an outcome | yes | co-mention without an outcome term yields no label outcome |
